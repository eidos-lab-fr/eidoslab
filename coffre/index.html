A tiny Mac app for coding with AI

Your API keys, out of your .env files.

Keys stay in the macOS Keychain, behind Touch ID. Your projects and your coding agents only see references like coffre://openai.

Download for MacView the source

Free and open source · Apple silicon · macOS 14 or later. The app is not notarized by Apple. The first time, right-click it in Applications, choose Open, then confirm.

# .env — safe to share with an agent
OPENAI_API_KEY=coffre://openai
STRIPE_SECRET_KEY=coffre://stripe-test
APP_NAME=demo
$ coffre run -- npm run dev
Touch ID · give OPENAI_API_KEY, STRIPE_SECRET_KEY to “npm run dev”
▲ Ready on http://localhost:3000
The keys live in memory, for this command only.

Your keys and projects, at a glance

Drop a .env file on the window to move its keys out of it. Drop a project folder to see which variables are linked, missing or written in clear, and fix each one in a click.

What it does

In the Keychain

Each key is stored in the macOS Keychain. Reading it asks for Touch ID, or your Mac password.

In memory only

coffre run gives the keys to your command when it starts. They are never written to disk.

Agents never see a key

With the MCP server, Claude Code or Cursor asks for a key, a Coffre window opens, you paste it. The agent only gets the reference.

Finds what is missing

coffre check reads .env, .env.example and your code, and lists missing variables and keys written in clear.

No key in commits

coffre guard install stops a git commit that contains a key in clear, with the file and the line.

Moves your old keys

coffre import takes the keys out of an existing .env and leaves references in their place.

How it works

Add a key

From the shield in the menu bar, or with coffre add openai.

Write the reference

In .env: OPENAI_API_KEY=coffre://openai. This file can be read by anyone.

Run with Coffre

coffre run -- npm run dev, then Touch ID. The dialog names the command that gets the keys.

Connect your agent

One command for Claude Code. Coffre also works with Cursor, Claude Desktop and any MCP client.

claude mcp add coffre --scope user -- /Applications/Coffre.app/Contents/MacOS/Coffre mcp

Then tell the agent to use Coffre for API keys. It writes references, asks you for keys in a Coffre window, and starts the project with coffre run. When the output goes to the agent, a key printed by mistake is replaced by its reference.

Private by design

No account, no server, no sync. Coffre keeps nothing outside your Keychain. A command you allow receives the keys, so read the command in the Touch ID dialog before you confirm, especially when an agent started it.
